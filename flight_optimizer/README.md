# ✈️ Flight Optimizer (B12 Take-Home Assignment)

This project finds the cheapest flight per kilometer using the [Kiwi Tequila API](httpstequila-api.kiwi.com)  
It includes
- A Python CLI tool
- A FastAPI microservice
- Unit tests with `pytest`

---

## 🚀 Features
- Query cheapest flights per kilometer (`$  km`)
- Works with multiple destination cities
- Exposes results via CLI or HTTP API
- Unit tested with mocked Kiwi API responses
- API key loaded securely from `.env`
